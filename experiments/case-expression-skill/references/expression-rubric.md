# 四项内部检查

只用于理解文案和定位问题，不规定回复格式，也不直接充当改写提纲。

## 1. 这一节在整篇里承担什么作用？

看它是在交代起点、展示证据、暴露失败、说明动作、改变判断，还是补充边界。没有明确作用时，再判断是否需要删除或并入其他位置。

## 2. 关键判断有没有具体事实支撑？

检查判断附近是否有数据、对照结果、具体事件、用户行为或可回溯材料。事实与判断可以隔段出现，只要读者能自然建立联系。

## 3. 作者动作和判断是否容易找到？

读者应能分辨作者亲自做了什么，以及哪个结果改变了作者的判断。不要因为关系是隐含的，就强行补成完整逻辑句。

## 4. 有没有重复、绕句或不参与论证的信息？

区分：

- 为避免误解而必须保留的边界；
- 已经说过的解释；
- 动作被多层说明埋住的绕句；
- 不影响理解、判断或节奏的多余信息。

有些旁注、停顿和低信息句参与人物视角或阅读节奏，不要仅因“不推进论证”就删除。
